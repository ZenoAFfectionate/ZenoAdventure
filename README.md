## ✨ 项目特色

### 🎯 精心调校的操作手感

- **可变跳跃高度** — 轻按短跳，长按高跳，操控感丝滑流畅
- **土狼时间（Coyote Time）** — 离开平台后 0.17 秒内仍可起跳，告别"差一帧"的挫败感
- **跳跃缓冲（Jump Buffer）** — 落地前提前按跳跃，着地瞬间自动起跳
- **空中操控差异化** — 地面加速快、空中惯性大，兼顾精准与飘逸

### 🗺️ 五大主题关卡

| 关卡 | 主题 | 教学要素 |
|:----:|:----:|:-------|
| 1 | 🌿 Green Hills（绿丘） | 基础移动、跳跃、收集、角色技能教学、钥匙开门 |
| 2 | 🏜️ Desert Dash（沙漠） | 双向传送带节奏组合、飞行敌人、高低分支路线 |
| 3 | 🔮 Crystal Cave（水晶洞） | 梯子、浅水→深水渐进教学、水下支线与鱼 |
| 4 | 🌋 Lava Lake（熔岩湖） | 火焰敌人、连续熔岩跳跃、弹簧飞越终段 |
| 5 | 🏛️ Sky Temple（天空神殿） | 水平/垂直移动平台、底层恢复岛、空中终局路线 |

### 👾 十种敌人 AI 与终关首领

- **史莱姆** — 地面巡逻，踩踏击败
- **蜜蜂 / 苍蝇** — 蜜蜂宽幅横向巡逻，苍蝇窄幅纵向俯冲，轨迹可读
- **锯齿** — 不可踩踏；Sky Temple 另有**轨道锯齿**，沿短轨道往返且有端点预览
- **鱼** — 蓝鱼水中横向巡逻，紫鱼沿水柱上下游动
- **蜗牛** — 踩一次缩壳；空壳可以**踢出去撞倒其他敌人**（速度受限、连锁伤害限一次）
- **火焰史莱姆** — 更快的地面巡逻；被踩后留下带预警的短暂火焰，熄灭时有烟雾动画
- **尖刺史莱姆** — 无法踩踏，但可被冲刺或无敌星击破（+100 ARMOR BREAK 反馈）
- **青蛙** — 起跳前压缩下蹲并显示落点阴影，节奏可读
- **方块守门者（首领）** — 镇守 Sky Temple 出口：落点预警 → 天降砸落 → 双向地面冲击波 → 暴露弱点，踩踏三次开门；所有角色均可无伤击败，失败从首领前检查点重来

### 🧙 角色技能

- **Green** — `X` 发动冲刺斩击，移动速度更快
- **Pink** — 空中再次按跳跃发动二段跳，基础跳跃更高
- **Purple** — `C` 让敌人减速 3 秒，受伤无敌时间更长
- **Beige** — 无技能经典模式，生命上限较低，适合自我挑战

### 🏆 丰富的激励机制

- **连击系统** — 连续踩踏敌人获得倍数得分（x2、x3…），2 秒内未踩踏则重置
- **时间奖励** — 通关越快，奖励越高（最高 +500 分）
- **收集进度** — HUD 实时显示物品收集率
- **最高分存档** — 自动保存历史最高分，挑战自我极限
- **三星章评价** — 通关、全收集、限时无死亡分别获得星章
- **关卡选择** — 通关后解锁下一关，并显示最佳时间和历史星章
- **目标时间** — 每关拥有独立目标时间，超时仍可继续探索
- **飞字反馈** — 收集物品和击败敌人时飘出得分文字

### 🧩 精巧机关设计

- **双向传送带** — 顺带加速、逆带减速但可对抗，Desert Dash 有专门的节奏教学组合
- **水平 / 垂直移动平台** — Sky Temple 的垂直升降台会平稳载人升降，首次出现保持低速
- **底层恢复岛** — Sky Temple 底层是 4 座被虚空隔开的安全岛，岛上弹簧送你重返空中路线，坠落可恢复但无法绕关
- **渐进水域教学** — Crystal Cave 先浅水趟行、再深入潜水，水下暗礁保证必有出路
- **弹簧飞越** — Lava Lake 终段踩弹簧冲天飞越熔岩，沿途金币弧线奖励
- **角色化教学提示** — Green Hills 按当前角色显示技能教学（Beige 显示 Classic Challenge），首次拾取无敌星弹出规则说明；提示只出现一次，可在 Controls 界面按 `T` 关闭

### 🎨 视觉与音效

- **双层视差滚动背景** — 远近层次分明，营造空间纵深感
- **粒子特效系统** — 收集爆发、落地扬尘、受伤飞溅
- **屏幕震动** — 受到伤害时画面抖动，打击感十足
- **弹簧动画** — 踩到弹簧时显示压缩状态
- **10 种音效** — 跳跃、收集、宝石、受伤、弹簧、踩踏等全覆盖
- **平滑摄像机跟随** — Lerp 插值跟随，画面不突兀

## 🎮 游玩方法

### 安装与启动

```bash
# 确保已安装 Python 3.10+
pip install -r requirements.txt

# 启动游戏
python3 main.py
```

### 操作说明

| 操作 | 按键 |
|:-----|:-----|
| 左右移动 | `←` `→` 或 `A` `D` |
| 跳跃 | `空格` / `Z` / `J` / `↑` / `W` |
| 蹲下 | `↓` 或 `S` |
| 攀爬梯子 | 站在梯子上按 `↑` 或 `W` |
| 冲刺技能 | Green 使用 `X` |
| 时间减速 | Purple 使用 `C` |
| 暂停 | `ESC` |
| 静音切换 | `M` |
| 教学提示开关 | Controls 界面按 `T` |

### 游戏流程

1. **主菜单** → 选择「Start Game」开始冒险，或进入已解锁的关卡
2. **角色选择** → 从 4 名能力不同的角色中选择玩法
3. **关卡探索** → 跑跳穿关，沿途收集金币和宝石
4. **钥匙与锁** → 找到钥匙才能打开锁，通过锁后才能到达出口
5. **检查点旗帜** → 触碰旗帜设定重生点，掉落悬崖不会回到起点
6. **到达门** → 走进门内完成关卡，进入下一关；终关需先击败方块守门者解除封印
7. **通关** → 完成全部 5 关后展示总分和用时

游戏进度保存在 `save.json`，包含已解锁关卡、最佳时间、星章、最高分和角色通关记录。

### 游戏技巧

- 💡 **踩踏敌人**：从正上方落下可以踩踏敌人，获得弹跳和分数
- 💡 **连击踩踏**：连续踩踏多个敌人，分数翻倍增长
- 💡 **弹簧远跳**：踩到弹簧可以弹得很高，利用它到达高处收集品
- 💡 **单向平台**：木板平台可以从下方穿过，只有从上方落下才会站住
- 💡 **充能水晶**：蓝紫色水晶会立即清空主动技能冷却
- 💡 **洞穴水池**：桥面是安全主路，潜入水下可以取得额外宝石；池边暗礁能帮你轻松上岸
- 💡 **火焰史莱姆**：踩踏后会留下短暂火焰，冲刺击杀则不会；Purple 的减速会延长火焰预警时间
- 💡 **垂直升降台**：站上去会被平稳载到高处，看准时机起跳
- 💡 **天空神殿恢复岛**：掉到底层别慌，每座岛上的弹簧都能把你送回空中路线
- 💡 **蜗牛壳妙用**：把缩壳的蜗牛踢出去，可以撞倒路上的其他敌人
- 💡 **轨道锯齿**：看清轨道两端的位置，等它滑到远端再通过
- 💡 **首领战**：躲开落点标记、跳过地面冲击波，等它露出疲态再踩；紫减速能让所有预警更慢
- 💡 **分支奖励**：高处或危险路线通常藏有宝石、无敌星和生命补给
- 💡 **短跳高跳**：轻按跳跃键做短跳，长按做高跳，灵活应对不同场景
